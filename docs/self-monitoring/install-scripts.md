# Install script events

`install.sh` and `install.ps1` send events when `DT_ENVIRONMENT` is set: one when they start and one when the install completes, fails, or is cancelled. Their `executionId` is generated by the script and differs from the `executionId` of the `dtwiz` runs that follow.

```text
invoked ──▶ completed | failed | cancelled
```

Install script events have their own properties instead of the common ones:

| Property      | Values                                                                                                                                                                                                                                          | Description                                                                    |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `executionId` | `3ab`                                                                                                                                                                                                                                           | Links the events of one script run                                             |
| `script`      | `sh`, `ps1`                                                                                                                                                                                                                                     | Install script that ran                                                        |
| `step`        | `invoked`, `completed`, `failed`, `cancelled`                                                                                                                                                                                                   | Execution stage                                                                |
| `os`          | `darwin`, `linux`, `windows`                                                                                                                                                                                                                    | Operating system                                                               |
| `channel`     | `stable`, `main`, `tag`                                                                                                                                                                                                                         | Requested release source                                                       |
| `tag`         | `snapshot-main`                                                                                                                                                                                                                                 | Requested release tag, when set                                                |
| `version`     | `1.14.0`                                                                                                                                                                                                                                        | Version being installed, once resolved                                         |
| `error`       | `unknown_argument`, `unsupported_os`, `unsupported_arch`, `curl_missing`, `github_unreachable`, `release_not_found`, `install_dir_failed`, `prompt_failed`, `download_failed`, `extract_failed`, `binary_missing`, `move_failed`, `interrupted` | Failure reason. `interrupted` is sent on a `cancelled` run stopped with Ctrl+C |

`invoked`:

```json
{
  "title": "dtwiz install script",
  "properties": {
    "executionId": "5c1",
    "script": "sh",
    "step": "invoked",
    "os": "darwin",
    "channel": "stable"
  }
}
```

`completed`:

```json
{
  "title": "dtwiz install script",
  "properties": {
    "executionId": "5c1",
    "script": "sh",
    "step": "completed",
    "os": "darwin",
    "channel": "stable",
    "version": "1.14.0"
  }
}
```

`failed`:

```json
{
  "title": "dtwiz install script",
  "properties": {
    "executionId": "5c1",
    "script": "sh",
    "step": "failed",
    "os": "darwin",
    "channel": "stable",
    "version": "1.14.0",
    "error": "download_failed"
  }
}
```

`cancelled`:

```json
{
  "title": "dtwiz install script",
  "properties": {
    "executionId": "5c1",
    "script": "ps1",
    "step": "cancelled",
    "os": "windows",
    "channel": "stable",
    "error": "interrupted"
  }
}
```
